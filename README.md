# AdaPID: Adaptive Path-Integral Diffusion

This repository contains the Jupyter/Python code used to generate all figures in the longer (original) version of the paper:

**“Adaptive Path-Integral Diffusion (AdaPID)”**  
Michael (Misha) Chertkov and Hamirdreza Behjoo, University of Arizona
available at https://arxiv.org/abs/2512.11858.

Notice that a shorter (journal) version of the paper has a separate repository https://github.com/mchertkov/ShortAdaPID

## Contents
- `guidedpid_api/` — Python modules implementing the AdaPID solver  
- Jupyter notebooks generating all figures appearing in the paper
